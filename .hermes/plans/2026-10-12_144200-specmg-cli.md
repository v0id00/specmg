# Plan: `specmg` — Spec Management CLI (Go)

## Goal

Git-savvy, AI-friendly bir Go CLI: bir projedeki spec dosyalarını, içindeki gereksinim/kabul kriteri/bağlenti/açık soru maddelerini, status akışını ve filtrelenebilir listeleri dosyaları elle açmadan yönetmek.

## Current context / assumptions

- Repo: `/home/webticari/Belgeler/spec-mg` — şu an **sadece `.git` var**, boş repo. `git log` boş.
- Toolchain: `go1.24.2 linux/amd64` mevcut.
- Depo adı ve binary adı: `specmg` — **kullanıcı onayladı**.
- Saklama formatı: **markdown + YAML frontmatter**, dosya başına bir spec, `specs/` dizini. Gerekçe: git-diff dostu, AI/agent'ların okuması kolay, harici bağımlılık yok. SQLite/YAGNI.
- Dil kararları: kod, identifier, commit mesajları ve CLI çıktıları **İngilizce**. Plan Türkçe.
- Kullanıcının CLI konvansiyonları uygulanır: her komut `--help`, write komutlarında `--dry-run`, global `--json` (human + JSON dual output), `--verbose`.
- Bu araç mevcut `sdd` skill'lerinin (spec-driven-development) yazdığı formatla **uyumlu** olacak: `specs/NNNN-slug.md`, `Status:`, `- [ ] ACn:` kavramları korunur; araç kendi madde ID'lerini (`REQ-1`, `AC-1`…) markdown gövdesine gömer.
- Implementer sıfır context ile geliyor; tüm формат sözleşmesi aşağıdaki "Spec file format contract" bölümü tek yetkilidir.

## Architecture / proposed approach

Tek binary, standart Go projesi: `internal/spec` (model + parse + render, saf fonksiyonlar), `internal/store` (repo root bulma, listeleme, atomik yazma), `internal/cli` (cobra komutları, sadece orches­tration), `internal/output` (human tablo / `--json` çıktısı). Body, AST yerine **satır-tabanlı** parse edilir (regex ile `REQ-/AC-/Q-/L-` maddeleri), render edilirken model tam geri yazılır — dosyanın sahibi CLI'dir, format normalizasyonu kabul edilir (bkz. Risks). Tüm I/O `os`/`afero` benzeri soyutlama olmadan doğrudan `os` üzerinden; testler `t.TempDir()` kullanır.

## Spec file format contract (tek yetkilidir)

Dosya: `specs/NNNN-<slug>.md` (`NNNN` 4 haneli sıfır dolgu, slug lowercase-hyphen).

```markdown
---
id: "0001"
slug: retry-budget
title: Retry budget
status: draft
owner: alice
created: 2026-10-12
updated: 2026-10-12
tags: [backend, reliability]
superseded_by: ""          # opsiyonel
rejected_reason: ""        # opsiyonel
---

## Purpose

Prose metin. Serbest; CLI tarafından okunmaz, aynen korunur.

## Requirements

- **REQ-1**: The client SHALL retry failed calls at most 3 times.

## Links

- **L-1**: implements -> 0002-other-slug

## Acceptance Criteria

- [ ] **AC-1**: `specmg list` exits 0 on an empty specs dir.
- [x] **AC-2**: Already-verified criterion.

## Open Questions

- **Q-1** [blocking]: Should backoff be exponential?
- **Q-2** [resolved]: What is the max retry count?

## Decision Log

| Date | Decision | Rationale |
|------|----------|-----------|
| 2026-10-12 | Max 3 retries | Simplicity |
```

Kurallar:

- `status` enum'u: `draft | in_review | approved | implemented | verified | superseded | rejected`. Başka değer kabul edilmez.
- Madde satırları tam olarak bu formatta yazılır (regex): `^- \*\*(REQ|AC|Q|L)-(\d+)\*\*(:| \[(blocking|resolved)\]:|: ->)` — pratikte parse regex'i: `^- \*\*(REQ|AC|Q|L)-(\d+)\*\*(?: \[(blocking|resolved)\])?: ?(.*)$`, AC satırları `- [ ]` / `- [x]` prefix'i alır.
- Link satırı: `- **L-1**: <rel> -> <target>`; `<rel>` enum: `implements | relates | blocks | depends_on | supersedes`.
- Section sırası sabittir: `Purpose`, `Requirements`, `Links`, `Acceptance Criteria`, `Open Questions`, `Decision Log`, bilinmeyen/ek section'lar sonda korunur.
- Render, parse edilen modelden dosyayı **byte-deterministik** yeniden üretir (canonical dosyalar round-trip'te birebir aynı çıkar).
- ID'ler tip başına `max+1` ile otomatik atanır.
- `updated` alanı her write işlemde bugünün tarihiyle (UTC, `2006-01-02`) güncellenir.

```go
package spec

import (
	"fmt"
	"strconv"
	"strings"
)

const (
	StatusDraft      = "draft"
	StatusInReview   = "in_review"
	StatusApproved   = "approved"
	StatusImplemented = "implemented"
	StatusVerified   = "verified"
	StatusSuperseded = "superseded"
	StatusRejected   = "rejected"
)

var Statuses = []string{
	StatusDraft, StatusInReview, StatusApproved, StatusImplemented,
	StatusVerified, StatusSuperseded, StatusRejected,
}

func ValidStatus(s string) bool {
	for _, v := range Statuses {
		if v == s {
			return true
		}
	}
	return false
}

var linkRels = map[string]bool{
	"implements": true, "relates": true, "blocks": true,
	"depends_on": true, "supersedes": true,
}

func ValidRel(r string) bool { return linkRels[r] }

// ParseItemID parses "REQ-1" -> ("REQ", 1, true).
func ParseItemID(s string) (typ string, num int, ok bool) {
	parts := strings.SplitN(s, "-", 2)
	if len(parts) != 2 {
		return "", 0, false
	}
	typ = strings.ToUpper(parts[0])
	switch typ {
	case "REQ", "AC", "Q", "L":
	default:
		return "", 0, false
	}
	n, err := strconv.Atoi(parts[1])
	if err != nil || n < 1 {
		return "", 0, false
	}
	return typ, n, true
}

type Frontmatter struct {
	ID             string   `yaml:"id"`
	Slug           string   `yaml:"slug"`
	Title          string   `yaml:"title"`
	Status         string   `yaml:"status"`
	Owner          string   `yaml:"owner"`
	Created        string   `yaml:"created"`
	Updated        string   `yaml:"updated"`
	Tags           []string `yaml:"tags"`
	SupersededBy   string   `yaml:"superseded_by,omitempty"`
	RejectedReason string   `yaml:"rejected_reason,omitempty"`
}

type Requirement struct{ Num int; Text string }
type Criterion struct{ Num int; Text string; Done bool }
type Question struct{ Num int; Text string; Blocking, Resolved bool }
type Link struct{ Num int; Rel, Target string }

type Spec struct {
	FM         Frontmatter
	Purpose    string // raw markdown, "## Purpose" altı
	Extra      string // bilinmeyen section'lar, sonda korunur
	Reqs       []Requirement
	Links      []Link
	Criteria   []Criterion
	Questions  []Question
	DecisionLog string // "## Decision Log" altı raw (tablo)
}

// Filename returns "NNNN-slug.md" per the format contract.
func (s *Spec) Filename() string { return s.FM.ID + "-" + s.FM.Slug + ".md" }

// Path returns specs-relative path.
func (s *Spec) Path(dir string) string { return dir + "/" + s.Filename() }

// NextNum returns max(num)+1 across items of one type (0 → 1).
func NextNum[T interface{ ~struct{ Num int; Text string } }](items []T) int { return 0 } //见下方泛型なし版
```

```go
package spec

import (
	"errors"
	"fmt"
	"regexp"
	"strconv"
	"strings"

	"gopkg.in/yaml.v3"
)

var (
	reItem  = regexp.MustCompile(`^[-*] \*\*(REQ|AC|Q|L)-(\d+)\*\*(?: \[(blocking|resolved)\])?: ?(.*)$`)
	reCheck = regexp.MustCompile(`^[-*] \[( |x|X)\] \*\*AC-(\d+)\*\*: ?(.*)$`)
	reLink  = regexp.MustCompile(`^[-*] \*\*L-(\d+)\*\*: ?(\w+) -> (\S+)$`)
	reHead  = regexp.MustCompile(`^## (.+)$`)
)

func Parse(data []byte) (*Spec, error) {
	txt := strings.ReplaceAll(string(data), "\r\n", "\n")
	if !strings.HasPrefix(txt, "---\n") {
		return nil, errors.New("missing YAML frontmatter")
	}
	end := strings.Index(txt[4:], "\n---")
	if end < 0 {
		return nil, errors.New("unterminated frontmatter")
	}
	var fm Frontmatter
	if err := yaml.Unmarshal([]byte(txt[4:4+end+1]), &fm); err != nil {
		return nil, fmt.Errorf("frontmatter: %w", err)
	}
	if fm.ID == "" || fm.Slug == "" || fm.Status == "" {
		return nil, errors.New("frontmatter requires id, slug, status")
	}
	if !ValidStatus(fm.Status) {
		return nil, fmt.Errorf("invalid status %q", fm.Status)
	}
	s := &Spec{FM: fm}
	rest := txt[4+end+5:] // "---\n" sonrası

	section, lineBuf := "", []string{}
	flush := func() {
		body := strings.TrimSpace(strings.Join(lineBuf, "\n"))
		switch section {
		case "Purpose":
			s.Purpose = body
		case "Decision Log":
			s.DecisionLog = body
		case "":
		default:
			if body != "" {
				if s.Extra != "" {
					s.Extra += "\n\n"
				}
				s.Extra += "## " + section + "\n\n" + body
			}
		}
		lineBuf = nil
	}
	for _, line := range strings.Split(rest, "\n") {
		if m := reHead.FindStringSubmatch(line); m != nil {
			flush()
			section = strings.TrimSpace(m[1])
			continue
		}
		if strings.TrimSpace(line) == "" && len(lineBuf) == 0 {
			continue
		}
		if section == "Requirements" {
			if m := reItem.FindStringSubmatch(line); m != nil && m[1] == "REQ" {
				n, _ := strconv.Atoi(m[2])
				s.Reqs = append(s.Reqs, Requirement{Num: n, Text: m[4]})
				continue
			}
		}
		if section == "Acceptance Criteria" {
			if m := reCheck.FindStringSubmatch(line); m != nil {
				n, _ := strconv.Atoi(m[2])
				s.Criteria = append(s.Criteria, Criterion{Num: n, Text: m[3], Done: m[1] == "x" || m[1] == "X"})
				continue
			}
		}
		if section == "Links" {
			if m := reLink.FindStringSubmatch(line); m != nil {
				n, _ := strconv.Atoi(m[1])
				s.Links = append(s.Links, Link{Num: n, Rel: m[2], Target: m[3]})
				continue
			}
		}
		if section == "Open Questions" {
			if m := reItem.FindStringSubmatch(line); m != nil && m[1] == "Q" {
				n, _ := strconv.Atoi(m[2])
				q := Question{Num: n, Text: m[4], Blocking: m[3] == "blocking", Resolved: m[3] == "resolved"}
				s.Questions = append(s.Questions, q)
				continue
			}
		}
		lineBuf = append(lineBuf, line)
	}
	flush()
	return s, nil
}
```

```go
package spec

import (
	"bytes"
	"fmt"
	"strings"

	"gopkg.in/yaml.v3"
)

func Render(s *Spec) []byte {
	var b bytes.Buffer
	b.WriteString("---\n")
	yaml.NewEncoder(&b).Encode(s.FM)
	b.WriteString("---\n\n")

	section := func(name, body string) {
		b.WriteString("## " + name + "\n\n")
		b.WriteString(strings.TrimSpace(body))
		b.WriteString("\n\n")
	}
	section("Purpose", s.Purpose)
	b.WriteString("## Requirements\n\n")
	for _, r := range s.Reqs {
		fmt.Fprintf(&b, "- **REQ-%d**: %s\n", r.Num, r.Text)
	}
	b.WriteString("\n## Links\n\n")
	for _, l := range s.Links {
		fmt.Fprintf(&b, "- **L-%d**: %s -> %s\n", l.Num, l.Rel, l.Target)
	}
	b.WriteString("\n## Acceptance Criteria\n\n")
	for _, c := range s.Criteria {
		mark := " "
		if c.Done {
			mark = "x"
		}
		fmt.Fprintf(&b, "- [%s] **AC-%d**: %s\n", mark, c.Num, c.Text)
	}
	b.WriteString("\n## Open Questions\n\n")
	for _, q := range s.Questions {
		tag := ""
		switch {
		case q.Resolved:
			tag = " [resolved]"
		case q.Blocking:
			tag = " [blocking]"
		}
		fmt.Fprintf(&b, "- **Q-%d**%s: %s\n", q.Num, tag, q.Text)
	}
	b.WriteString("\n## Decision Log\n\n")
	b.WriteString(strings.TrimSpace(s.DecisionLog))
	b.WriteString("\n")
	if strings.TrimSpace(s.Extra) != "" {
		b.WriteString("\n")
		b.WriteString(strings.TrimSpace(s.Extra))
		b.WriteString("\n")
	}
	return b.Bytes()
}
```

```go
// FindRoot walks up from dir looking for a "specs" dir (or .git as fallback marker).
func FindRoot(dir string) (string, error) {
	d, err := filepath.Abs(dir)
	if err != nil {
		return "", err
	}
	for {
		if st, err := os.Stat(filepath.Join(d, "specs")); err == nil && st.IsDir() {
			return d, nil
		}
		p := filepath.Dir(d)
		if p == d {
			return "", errors.New("no specs/ directory found above " + dir)
		}
		d = p
	}
}

// Save writes atomically (temp file + rename) and bumps "updated" to today (UTC).
func Save(root, dir string, s *spec.Spec) error {
	s.FM.Updated = timeNow()
	path := filepath.Join(root, dir, s.Filename())
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, spec.Render(s), 0o644); err != nil {
		return err
	}
	return os.Rename(tmp, path)
}

// timeNow is a var for tests to stub.
var timeNow = func() string { return time.Now().UTC().Format("2006-01-02") }

// Load resolves "0001", "retry-budget" or "0001-retry-budget".
func Load(root, dir, ref string) (*spec.Spec, error) {
	p := filepath.Join(root, dir)
	entries, err := os.ReadDir(p)
	if err != nil {
		return nil, err
	}
	for _, e := range entries {
		if e.IsDir() || !strings.HasSuffix(e.Name(), ".md") {
			continue
		}
		if strings.TrimSuffix(e.Name(), ".md") == ref ||
			strings.SplitN(e.Name(), "-", 2)[0] == ref ||
			strings.TrimSuffix(strings.TrimPrefix(e.Name(), strings.SplitN(e.Name(), "-", 2)[0]+"-"), ".md") == ref {
			b, err := os.ReadFile(filepath.Join(p, e.Name()))
			if err != nil {
				return nil, err
			}
			return spec.Parse(b)
		}
	}
	return nil, fmt.Errorf("spec %q not found in %s", ref, p)
}

// List parses every spec file, sorted by ID.
func List(root, dir string) ([]*spec.Spec, error) {
	p := filepath.Join(root, dir)
	entries, err := os.ReadDir(p)
	if err != nil {
		return nil, err
	}
	var out []*spec.Spec
	for _, e := range entries {
		if e.IsDir() || !strings.HasSuffix(e.Name(), ".md") {
			continue
		}
		b, err := os.ReadFile(filepath.Join(p, e.Name()))
		if err != nil {
			return nil, err
		}
		s, err := spec.Parse(b)
		if err != nil {
			return nil, fmt.Errorf("%s: %w", e.Name(), err)
		}
		out = append(out, s)
	}
	sort.Slice(out, func(i, j int) bool { return out[i].FM.ID < out[j].FM.ID })
	return out, nil
}

// NextID returns the next "NNNN" (max+1, zero-padded to 4).
func NextID(root, dir string) (string, error) {
	all, err := List(root, dir)
	if err != nil {
		return "", err
	}
	max := 0
	for _, s := range all {
		n, err := strconv.Atoi(s.FM.ID)
		if err == nil && n > max {
			max = n
		}
	}
	return fmt.Sprintf("%04d", max+1), nil
}

// Slugify makes a URL-safe lowercase-hyphen slug.
func Slugify(title string) string {
	s := strings.ToLower(title)
	s = strings.Map(func(r rune) rune {
		switch {
		case r >= 'a' && r <= 'z', r >= '0' && r <= '9':
			return r
		case r == ' ', r == '_', r == '-', r == '/':
			return '-'
		default:
			return -1 // Türkçe karakterler de buradan geçer: ı→i için Locale C gerekmez, basitlik adına ASCII dışı düşer
		}
	}, s)
	return strings.Trim(s, "-")
}
```

```go
func JSON(w io.Writer, v any) error {

// Table writes aligned columns.
func Table(w io.Writer, header []string, rows [][]string) error {
	tw := tabwriter.NewWriter(w, 2, 4, 2, ' ', 0)
	fmt.Fprintln(tw, join(header))
	for _, r := range rows {
		fmt.Fprintln(tw, join(r))
	}
	return tw.Flush()
}

func join(cols []string) string {
	out := ""
	for i, c := range cols {
		if i > 0 {
			out += "\t"
		}
		out += c
	}
	return out
}
```

```go
package cli

import (
	"fmt"
	"strconv"

	"github.com/spf13/cobra"
	"github.com/v0id00/specmg/internal/output"
	"github.com/v0id00/specmg/internal/spec"
)

var reqCmd = &cobra.Command{Use: "req", Short: "Manage requirements"}
var reqListCmd = &cobra.Command{
	Use:   "list <id|slug>",
	Args:  cobra.ExactArgs(1),
	RunE: func(cmd *cobra.Command, args []string) error {
		_, s, err := mustLoad(args[0])
		if err != nil {
			return err
		}
		if flagJSON {
			return output.JSON(cmd.OutOrStdout(), s.Reqs)
		}
		var rows [][]string
		for _, r := range s.Reqs {
			rows = append(rows, []string{"REQ-" + strconv.Itoa(r.Num), r.Text})
		}
		return output.Table(cmd.OutOrStdout(), []string{"ID", "TEXT"}, rows)
	},
}
var reqAddCmd = &cobra.Command{
	Use:   "add <id|slug> <text>",
	Args:  cobra.ExactArgs(2),
	RunE: func(cmd *cobra.Command, args []string) error {
		root, s, err := mustLoad(args[0])
		if err != nil {
			return err
		}
		n := 0
		for _, r := range s.Reqs {
			if r.Num > n {
				n = r.Num
			}
		}
		s.Reqs = append(s.Reqs, spec.Requirement{Num: n + 1, Text: args[1]})
		if flagDryRun {
			fmt.Fprintf(cmd.OutOrStdout(), "would add REQ-%d\n", n+1)
			return nil
		}
		if err := saveOrDry(root, s); err != nil {
			return err
		}
		fmt.Fprintf(cmd.OutOrStdout(), "added REQ-%d to %s\n", n+1, s.FM.ID)
		return nil
	},
}
var reqRmCmd = &cobra.Command{
	Use:   "rm <id|slug> <REQ-N>",
	Args:  cobra.ExactArgs(2),
	RunE: func(cmd *cobra.Command, args []string) error {
		root, s, err := mustLoad(args[0])
		if err != nil {
			return err
		}
		_, num, ok := spec.ParseItemID(args[1])
		if !ok {
			return fmt.Errorf("bad item id %q (want REQ-N)", args[1])
		}
		out := s.Reqs[:0]
		found := false
		for _, r := range s.Reqs {
			if r.Num == num {
				found = true
				continue
			}
			out = append(out, r)
		}
		if !found {
			return fmt.Errorf("REQ-%d not found in %s", num, s.FM.ID)
		}
		s.Reqs = out
		if err := saveOrDry(root, s); err != nil {
			return err
		}
		fmt.Fprintf(cmd.OutOrStdout(), "removed REQ-%d from %s\n", num, s.FM.ID)
		return nil
	},
}

func init() {
	reqCmd.AddCommand(reqListCmd, reqAddCmd, reqRmCmd)
	rootCmd.AddCommand(reqCmd)
}
```

`internal/cli/lint.go` iskeleti:

```go
package cli

import (
	"fmt"

	"github.com/spf13/cobra"
	"github.com/v0id00/specmg/internal/spec"
	"github.com/v0id00/specmg/internal/store"
)

type lintProblem struct {
	File    string `json:"file"`
	Level   string `json:"level"` // "error" | "warning"
	Message string `json:"message"`
}

type lintFail struct{ n int }

func (e lintFail) Error() string { return fmt.Sprintf("lint: %d problem(s)", e.n) }

var lintStrict bool

var lintCmd = &cobra.Command{
	Use:   "lint",
	Short: "Check all specs for format and consistency problems",
	RunE: func(cmd *cobra.Command, args []string) error {
		root, err := resolveRoot()
		if err != nil {
			return err
		}
		all, err := store.List(root, flagDir)
		if err != nil {
			return err
		}
		ids := map[string]bool{}
		for _, s := range all {
			ids[s.FM.ID+"-"+s.FM.Slug] = true
		}
		var probs []lintProblem
		add := func(f, lvl, msg string) {
			probs = append(probs, lintProblem{f, lvl, msg})
		}
		for _, s := range all {
			file := "specs/" + s.Filename()
			if s.FM.Status == spec.StatusApproved {
				for _, q := range s.Questions {
					if q.Blocking && !q.Resolved {
						add(file, "error", fmt.Sprintf("approved spec has unresolved blocking Q-%d", q.Num))
					}
				}
			}
			if s.FM.Status == spec.StatusSuperseded && s.FM.SupersededBy == "" {
				add(file, level(lintStrict), "superseded spec missing superseded_by")
			}
			for _, l := range s.Links {
				if !ids[l.Target] {
					add(file, "error", fmt.Sprintf("dangling link L-%d -> %s", l.Num, l.Target))
				}
			}
		}
		n := 0
		for _, p := range probs {
			if p.Level == "error" {
				n++
			}
		}
		if flagJSON {
			if err := output.JSON(cmd.OutOrStdout(), probs); err != nil {
				return err
			}
		} else {
			for _, p := range probs {
				fmt.Fprintf(cmd.OutOrStdout(), "%s: [%s] %s\n", p.File, p.Level, p.Message)
			}
			if n == 0 && len(probs) == 0 {
				fmt.Fprintln(cmd.OutOrStdout(), "lint: ok")
			}
		}
		if n > 0 {
			return lintFail{n}
		}
		return nil
	},
}

func level(strict bool) string {
	if strict {
		return "error"
	}
	return "warning"
}

func init() {
	lintCmd.Flags().BoolVar(&lintStrict, "strict", false, "treat warnings as errors")
	rootCmd.AddCommand(lintCmd)
}
```

## Risks, tradeoffs, and open questions

1. **Format sahipliği**: CLI dosyayı her yazışta yeniden render eder; elle eklenen markdown biçimlendirmesi (yorumlar, farklı bullet stili, madde içi çok satır metin) normalleşir/kaybolur. Kabul edildi: dosyanın sahibi CLI. Mitigasyon: `Purpose`/`Decision Log`/bilinmeyen section'lar raw korunur; çok satırlı maddeler desteklenmez (YAGNI, belgelenecek).
2. **Binary adı / module yolu**: `specmg` + `github.com/v0id00/specmg` tahmini. Kullanıcı farklı bir isim isterse Task 0'da değişir (tek `sed` işlemi, ucuz).
3. **`--tag` vs `--tags`**: plan `--tag` tekrarlanabilir flag olarak seçti (cobra `StringSliceVar`); `--tags a,b` de çalışır.
4. **Slug uniqueness**: `set --slug` çakışan slug üretirse iki dosya aynı ada düşer — MVP'de kontrol yok. Open question: ekleyelim mi? (Öneri: `set` içinde `Load` ile çakışma kontrolü, 5 satır, sonraki iterasyonda.)
5. **Türkçe başlıklar**: `Slugify` ASCII dışı karakterleri düşer ("Şubat" → "ubat" yerine "ubat"? — "Ş" düşer, "ubat" kalır). Alternatif: `golang.org/x/text/unicode/norm` + transliterasyon. MVP'de basit ASCII-only; open question olarak bırakıldı.
6. **Evidence shell çalıştırma**: `--cmd` yalnızca kullanıcı input'undan gelir; `sh -c` tam shell komutu desteği için bilinçli (Task 17 güvenlik notu). Fail-closed: exit≠0 → AC check yok, hata exit 1.
7. **Concurrency**: iki CLI aynı anda yazarsa son yazar kazanır (atomic rename var, lock yok). Yeterli: tek kullanıcı/agent senaryosu.
8. **sdd uyumu**: mevcut `sdd-*` skill'lerin formatıyla uyumlu ama `sdd` CLI'nın `.sdd/cache.json`/`INDEX.md` mekanizmaları **kopyalanmadı** (YAGNI). Uzakta: `specmg index` komutu `specs/INDEX.md` üretebilir — open question.
